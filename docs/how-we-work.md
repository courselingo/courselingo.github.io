# 我们怎么做

一句话：**授权先过闸，术语表先冻结，然后逐讲产出，机检之后人工复核。**

## 五道关

### 1. 授权闸门 —— 不通过就拒绝构建

每门课在 `course.toml` 里逐**材料类型**记录授权（讲义 / 幻灯片 / 视频 / 作业 / 教材），
而不是一个笼统的布尔值 —— 因为同一门课不同材料的授权经常不同。

| 退出码 | 含义 |
| --- | --- |
| `0` | 通过 |
| `1` | 内容有问题（**可以修**） |
| `3` | **政策性拒绝**：授权明确不允许传播（**改内容没用**） |

《[授权说明](licensing.md)》里写了闸门的判定顺序。要点是：

- `output_mode = "transcript"`（逐字稿翻译）时，必须该类材料的授权**已核实为允许**，否则 `validate.py` 以**退出码 1** 拒绝。
- 课程明确不允许传播时，`validate.py` 与 `build.py` 都以**退出码 3** 拒绝，**不产出任何站点**，CI 的部署链条在第一步就断了。
- 配套的**双语原文对照**排版走同一道闸门：材料授权为 `false` 时，`build_site.py` **不注入**对照块。

**这道闸门是构建的一部分，不是文档里的口号。**

### 2. 术语表先冻结

`glossary.toml` 是核心资产：一个概念一个 key，全课程同译。
讲义正文用 `[[term:key]]` 标记术语，`validate.py` 检查两件事：

- 引用的 key 必须在术语表里存在；
- 术语表里出现的英文原词如果在正文里出现却没打标记 → 警告。

术语表没冻结就不开笔 —— 否则同一概念会在不同讲次里出现三种译法。

### 3. 逐讲产出 —— 讲解优先于译完

每篇内容的结构是固定的六段脉络（读者读完能回答的问题）：

| # | 段落职责 | 读者读完应能回答 |
| --- | --- | --- |
| 1 | 现状与痛点 | 「为什么要费这个劲？」 |
| 2 | 直觉做法为什么不行 | 「那我想的那个办法错在哪？」 |
| 3 | 核心思路 | 「它的主张是什么？」 |
| 4 | 机制怎么运转 | 「具体怎么做到的？」 |
| 5 | 代价与边界 | 「它不适用于什么情况？」 |
| 6 | 脉络回顾 | 「这一讲在整门课的位置？」 |

这不是文风偏好，而是**为了让基础薄弱的中文读者能跟着思路走完**：
先讲痛点，再给方案；术语首次出现给「中文（English）」，之后统一用中文。

### 4. 机检 —— 三道自动检查

| 检查 | 脚本 | 拦什么 |
| --- | --- | --- |
| **内容** | `validate.py` | 授权闸门、front matter 完整性、术语 key 存在性、**原文转载探测** |
| **配图** | `check_figures.py`（房规 SVG linter） | 手绘 SVG 的调色板、标签居中、墨迹边距等，要求 `0 error 0 warning` |
| **文风** | `check_style.py` | 六段脉络的锚点标题、用词规范等可机检条目 |

原文转载探测的阈值（为什么它能工作）：剥掉 Markdown 语法后 **> 400 字符**、
**ASCII 占比 ≥ 90%**、**空格数 ≥ 40** 的段落视为疑似整段照抄英文原文。

!!! warning "机器拦不住译文"
    上述探测针对的是**英文原文** —— 一篇全中文的**翻译**不会触发它。
    也就是说：翻译模式在机器层面**只有授权闸门这一道保护**。这正是闸门必须硬、
    以及下面第 5 步不可省的原因。

### 5. 人工复核

机器能查格式与转载痕迹，查不出「这段中文是翻译还是原创」。
所以每一篇在发布前都要有人读一遍，并对授权边界做一次确认。

## 内容形态与渲染方式

- **内容是纯 Markdown**：front matter + 正文 + 链接的配图，没有私有格式。
- **渲染是可替换的**：同一批 Markdown 可以用 MkDocs Material 渲染，
  也可以用平台自带的**零依赖**构建脚本渲染，还可以直接喂给 AI Agent（我们额外发布 `llms.txt`）。
  **换渲染器不需要改内容** —— 这是我们不在内容里绑定某个工具的原因。
- **可溯源**：每篇头部标注来源课程、对应讲次、官方链接与授权依据。

一个页面头部大致长这样：

```markdown
> 来源课程：MIT 6.5840 / 6.824 Distributed Systems
> 对应内容：Lecture 3 — Primary-Backup Replication
> 官方链接：https://pdos.csail.mit.edu/6.824/
> 授权依据：<已核实条款 / 待核实 —— 未核实不得发布>
> 本文为 CourseLingo 原创讲解，非官方材料，与原课程方无隶属关系。
```

## 署名与标注

- 任何涉及具体课程的页面都显著标注「**非官方 · 社区项目**」。
- **不使用任何学校的校徽或课程 Logo**，不暗示官方背书。
- 页面上的课程名称均为描述性引用，版权归原作者与院校所有。

## 下线机制

任何内容一旦被指出超出授权范围：**立即下线**（不回退讨论、不等核实结论）→
开 issue 记录决策 → 复盘该课程的授权判断是否有系统性偏差。

宁可错杀，不可拖延。
